# Provenance for review

The files in this candidate were copied from the local RPK PHP2Shell triage development workspace on 2026-10-22. The copy includes the Python package under `src/rpk_php2shell_triage/`, `pyproject.toml`, the two synthetic JSON examples, the two test modules, and a revised public-facing README. The original workspace and private project records are not part of this candidate.

The release thresholds and CVE descriptions in the package cite the [PHP release archive](https://www.php.net/archive/2026.php#2026-10-21-5) and the [first](https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp) and [second](https://github.com/php/php-src/security/advisories/GHSA-w8hw-w9fx-j79w) PHP security advisories. These are reference sources; the tool does not fetch them at runtime. Vendor and deployment status require fresh review at use time.

The saved-log indicator work adapts compact rule fragments from the public [ericmann/php2shell-ioc source at commit `7b099c1a87798bf29867a1c2c5bbf10f238d89af`](https://github.com/ericmann/php2shell-ioc/tree/7b099c1a87798bf29867a1c2c5bbf10f238d89af). The Python module uses the same OOM regex body as [upstream line 395](https://github.com/ericmann/php2shell-ioc/blob/7b099c1a87798bf29867a1c2c5bbf10f238d89af/php2shell-ioc.sh#L395) and the same ordered Apache signal alternatives as [upstream line 398](https://github.com/ericmann/php2shell-ioc/blob/7b099c1a87798bf29867a1c2c5bbf10f238d89af/php2shell-ioc.sh#L398). The synthetic tests reuse upstream example choices such as `134217728` bytes and FPM child `41` from [its log tests](https://github.com/ericmann/php2shell-ioc/blob/7b099c1a87798bf29867a1c2c5bbf10f238d89af/tests/cases/logs.sh#L9). PHP error strings and signal names are factual log syntax; their exact selection and arrangement here are treated as adapted provenance. The Python scanner's file checks, bounded hashing, output schema, and no-raw-line behavior are separate implementations. The complete upstream [MIT notice](https://github.com/ericmann/php2shell-ioc/blob/7b099c1a87798bf29867a1c2c5bbf10f238d89af/LICENSE) is preserved in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and must accompany any release containing the adapted material.

The example target names, timestamps, process IDs, file paths, and test log lines are synthetic fixtures. This review has not established that any output is safe to publish after running the tool on a real target. Real case packets, logs, hashes, line numbers, and outputs must stay outside the public source tree.
